## AntdUI

Open source・Free・Modern UI・Unified style

![demo](img/ant.jpg?raw=true)

### ✨Features

<table>
<tr>
<td width="33%">

**🔓 Open Source & Business-Friendly**

Licensed under Apache-2.0 with full source code available. Free for personal, commercial use, redistribution and customization with no barriers.

</td>
<td width="33%">

**🌈 High-quality Anti-aliased Text Rendering**

Optimized native text drawing with crisp font edges. Delivers sharp output on high-DPI displays and eliminates blurry WinForms text.

</td>
<td width="33%">

**🎨 Pure GDI Vector Graphics & Animation**

Pure code-based vector drawing with no external image assets. Smooth interruptible animations that respond instantly with no lag.

</td>
</tr>
<tr>
<td width="33%">

**😍 Native Emoji Rendering Support**

Breaks monochrome UI limitations by rendering colorful emojis natively. Adds vivid touch to tags, dashboards and chat interfaces.

</td>
<td width="33%">

**💎 Gaussian Blur Shadow Effects**

Industry-leading Gaussian blur shadow solution for WinForms. Creates native-quality window shadows and clear visual hierarchy.

</td>
<td width="33%">

**📦 Borderless Native Window**

Fully customizable borderless style with full native window capabilities: drag, resize, system hotkeys. Compatible from Win7 to Win11.

</td>
</tr>
<tr>
<td width="33%">

**👚 Flexible Theme System**

Built-in light & dark modes with customizable theme variables. One-click switching, aligned with Ant Design 5.0 specifications.

</td>
<td width="33%">

**📐 Interactive Safe Zone Mechanism**

Follows Amazon 2013 interaction safety guidelines. Reserves safe margins to prevent occlusion and keep all controls accessible.

</td>
<td width="33%">

**🌍 Globalization & Localization**

Extensible text resource localization support. Enables desktop apps to quickly adapt to multi-language markets worldwide.

</td>
</tr>
<tr>
<td width="33%">

**🦜 Native SVG Vector Rendering**

Loads and renders SVG icons natively with zero quality loss when scaling. Richer colors and consistent clarity compared to raster images.

</td>
<td width="33%">

**👓 Full DPI Adaptation**

Auto-detects system DPI changes. Controls, text and icons scale synchronously to avoid blurriness and broken layouts.

</td>
<td width="33%">

**🦺 AOT Compilation Support**

Supports AOT precompilation for deployment. Self-contained binaries without .NET runtime dependency. Faster startup and source protection.

</td>
</tr>
</table>
